# Inter-Operate `.github`

Organization defaults for community health files and issue templates.

Repos without their own `.github/ISSUE_TEMPLATE/` inherit templates from here.

**Path must be** `.github/ISSUE_TEMPLATE/` (not `ISSUE_TEMPLATE/` at repo root).

## Templates

| File | Purpose |
|------|---------|
| [`.github/ISSUE_TEMPLATE/bug_report.md`](.github/ISSUE_TEMPLATE/bug_report.md) | Default bug report (GitHub issue type: **Bug**) |
| [`.github/ISSUE_TEMPLATE/config.yml`](.github/ISSUE_TEMPLATE/config.yml) | Disable blank issues |
